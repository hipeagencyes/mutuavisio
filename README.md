
# Mutuavisió

Mutuavisió ([www.mutuavisio.com](https://www.mutuavisio.com/)) es la web de una óptica familiar ubicada en Barcelona, especializada en salud visual y atención personalizada. El sitio ofrece información sobre servicios ópticos, contacto, testimonios y detalles legales.

## Descripción

Mutuavisió es una óptica de confianza con más de 35 años de experiencia, dedicada a ofrecer revisiones visuales, gafas graduadas, lentillas, gafas de sol y asesoramiento profesional para toda la familia. El sitio web permite a los clientes conocer los servicios, horarios, dirección, y contactar fácilmente por WhatsApp, teléfono o email.

## Estructura del Proyecto

- `index.html`: Página principal con información sobre la óptica, servicios, testimonios y contacto.
- `aviso-legal.html`: Aviso legal.
- `politica-privacidad.html`: Política de privacidad.
- `css/`: Hojas de estilo (Bootstrap, estilos personalizados, plugins, esquemas de color).
- `fonts/`: Fuentes e iconos (Elegant Font, Et Line Font, FontAwesome, Icofont).
- `images/`: Imágenes (fondo, iconos, testimonios, UI).
- `js/`: Archivos JavaScript (scripts personalizados, plugins, validación de formularios).
